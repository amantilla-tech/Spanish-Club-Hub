# Spanish Club Learning Hub

A free, responsive starter website for a Spanish Club.

## Files
- `index.html` — website structure/content
- `style.css` — design and responsive layout
- `script.js` — mini quiz, mobile menu, and resource-submission button

## Member submissions
1. Create a free Google Form for resource submissions.
2. Ask for resource type, title, link, member name (optional), and a short reason/review.
3. Copy the Google Form link.
4. Open `script.js`.
5. Replace `PASTE-YOUR-GOOGLE-FORM-LINK-HERE` with the form URL.

Recommended workflow:
Members submit → club officers review → approved resources are added to the appropriate section.

## Free hosting with GitHub Pages
1. Create a free GitHub account.
2. Create a new repository named `spanish-club-hub`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. In the repository, open Settings → Pages.
5. Select the main branch as the deployment source.
6. GitHub will provide a free `github.io` website address.

No paid hosting or subscription is required.

## Easy customization
Search the HTML for:
- "Spanish Club Learning Hub" — site title
- "Spanish Club" — club name
- "Featured resource" — weekly feature
- Country cards — culture section
- Resource card text — club-specific links
